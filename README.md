# Machine learning

Kaggle problems, one folder per problem. Each folder is its own [uv](https://docs.astral.sh/uv/) project.

[concepts.md](concepts.md) collects the ML concepts that came up across the problems. [roadmap.md](roadmap.md) is the plan towards an ML engineer job: what is done and what comes next. [study_resources.md](study_resources.md) lists the courses, videos and documentation studied along the way.
